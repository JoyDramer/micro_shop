# 🛒 Мастер-карта проекта: Микросервисный Интернет-магазин + Аренда

## БЛОК I: Базовый E-commerce (Ядро)
- [x] **1. Инфраструктура:** Подняты PostgreSQL, Redis, RabbitMQ.
- [x] **2. Auth Service:** JWT-токены, разделение ролей (Admin/User).
- [x] **3. Order & Cart Service:** Корзина в Redis (Гости + Юзеры), логика слияния, оформление чека (Checkout), отправка `order_created` в RabbitMQ.
- [x] **4. Product Service (Saga Pattern):** Временная заморозка (Hold) на 15 минут вместо мгновенного списания остатков (защита от конфликтов при одновременной покупке и аренде).

## БЛОК II: Сложная бизнес-логика (Аренда)
- [x] **5. Rent Service (Базовый API):** Эндпоинты защищены, CRUD каталога аренды готов.
- [x] **6. Rent Service (Ядро логики):** Учет физических единиц (серийные номера) и проверка пересечения дат (Time-slot locks).

## БЛОК III: Финансы, Логистика, Оповещения
- [x] **7. Payment Service (Оплата):** Генерация ссылок на оплату. Обработка вебхуков `payment_success`.
- [x] **8. Delivery Service (Доставка):** Расчет стоимости доставки, добавление цены в общий чек.
- [ ] **9. Notification Service:** Слушатель RabbitMQ. Отправка Email/Telegram уведомлений клиенту.

## БЛОК IV: Сборка Бэкенда (Production-ready)
- [x] **10. API Gateway / Nginx:** Единая точка входа для маршрутизации запросов к микросервисам.
- [ ] **11. Тесты (Интеграционные):** Написание pytest для проверки транзакций и блокировок.
- [x] **12. Dockerization:** Написание Dockerfile для каждого сервиса и финального docker-compose.yml.

## БЛОК V: Frontend (Клиентская часть - React/Next.js)
- [ ] **13. Архитектура & UI/UX:** Развертывание проекта. Tailwind CSS + UI компоненты.
- [ ] **14. Авторизация & Сессии:** Работа с JWT и генерация гостевого `X-Session-ID` в `localStorage`.
- [ ] **15. Витрина & Аренда:** Отрисовка каталога товаров и календаря бронирования.
- [ ] **16. Корзина & Оформление:** Выезжающая корзина, страница Checkout со слиянием данных.
- [ ] **17. Админ-панель:** Скрытый раздел для управления каталогом и статусами.


Куда двигаемся дальше?
Теперь у нас есть мощный API. У нас три пути на выбор:

Путь 1: Начать Frontend (React / Next.js) 💻
Рекомендую этот вариант! Бэкенд уже достаточно умен, чтобы с ним мог работать клиентский интерфейс. Мы можем начать делать красивые карточки товаров, корзину, регистрацию и формы бронирования. Это даст мощный заряд мотивации, когда вы увидите свой проект "вживую" в браузере.

Путь 2: Сделать API Gateway (Nginx или FastAPI) 🌉
Сейчас сервисы висят на разных портах (order_service на 8000, rent_service на 8001 и т.д.). Фронтенду будет тяжело общаться с каждым отдельно. Мы можем создать единый "Шлюз", чтобы все запросы шли на один адрес api.mysite.com, а шлюз сам раскидывал их под капотом.

Путь 3: Подключить Оплату (Payment Service) 💳
Добавить интеграцию (например, Stripe, YooKassa или CloudPayments), чтобы генерировать реальные ссылки на оплату заказа или заморозку залога за аренду.
